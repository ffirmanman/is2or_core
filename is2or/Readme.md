# How to running code in the local

1. Copy config.local.example to config.local.php
2. Setup http_host and https_host to localhost:8000
3. Setup db_host db_name db_user and db_password to your local database
4. Running the code using php cli `php -S localhost:8000 -t is2or` is2or the whole path of the project
5. Open your browser and go to http://localhost:8000/admin385.php

# requirements
1. php >= 8.1
2. Mysql >= 5.7
